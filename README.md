# PocketAI

Нейросети прямо на телефоне: локальный запуск GGUF-моделей через [llama.cpp](https://github.com/ggml-org/llama.cpp), чат и доступ моделей к интернету. Дизайн — как у мобильной Winteria (палитра Pulse, день/ночь).

## Возможности

- **Локальный запуск** — модель работает на CPU телефона, без серверов и аккаунтов. Сборка под ARMv8.2 (dotprod + fp16).
- **Чат** — потоковый вывод, история чатов, Markdown и блоки кода, копирование, «ответить заново», скорость в ток/с. Шаблон чата берётся из самой модели. Между сообщениями переиспользуется KV-кэш, поэтому длинный диалог не пересчитывается заново.
- **🌐 Интернет для моделей** — кнопка в шапке чата. Приложение ищет в DuckDuckGo (запасной — Википедия), читает текст лучших страниц и отдаёт его модели. Ответ — со ссылками на источники `[1]`, `[2]`.
- **Модели** — скачивание с HuggingFace в один тап (Qwen2.5 0.5B/1.5B/3B, Llama 3.2 1B, Gemma 2 2B), своя ссылка на `.gguf` или импорт файла с телефона.
- **Reasoning-модели** (Qwen3, DeepSeek-R1) — блок `<think>` сворачивается в «Размышления».
- **Настройки** — системный промпт, temperature, длина ответа, размер контекста, потоки CPU, тема.

## Какую модель брать

| ОЗУ телефона | Модель |
|---|---|
| 3–4 ГБ | Qwen2.5 0.5B, Llama 3.2 1B |
| 4–6 ГБ | **Qwen2.5 1.5B** (рекомендуется, хорошо знает русский) |
| 6+ ГБ | Gemma 2 2B, Qwen2.5 3B |

## Сборка

APK собирает GitHub Actions при каждом пуше в `main` (`.github/workflows/android.yml`) и выкладывает в **Releases**.

Локально:
```bash
./scripts/get-llama.sh      # llama.cpp b6800 в ./llama.cpp
gradle :app:assembleRelease # нужен Android SDK + NDK
```

Ключ подписи `keystore/pocketai.jks` лежит в репо специально, чтобы каждую новую сборку можно было ставить поверх старой.

## Устройство

```
app/src/main/cpp/pocketai.cpp   JNI-мост к llama.cpp: загрузка, шаблон чата, генерация, кэш префикса
llm/LlamaEngine.kt              корутины, один поток для модели, обрезка истории под контекст
web/WebSearch.kt                поиск и чтение страниц (Jsoup)
data/                           модели (DownloadManager), чаты (JSON), настройки
ui/                             Compose-экраны в стиле Winteria Mobile
```
