# translatePro

Офлайн-переводчик для Android (Kotlin + Jetpack Compose, Google ML Kit).

- **Текст** — 59 языков, автоопределение языка, перевод на лету без интернета (после скачивания модели).
- **Голос** — диктовка (системное распознавание речи) и озвучка перевода (TTS).
- **Камера / фото** — распознавание текста на снимке или картинке из галереи и перевод.
- **История и избранное** — поиск, ☆, очистка.
- **Языки** — скачивание/удаление офлайн-моделей (~30 МБ каждая).
- Перевод выделенного текста из любого приложения (меню «translatePro») и через «Поделиться».

Сборка: `./gradlew assembleRelease`
